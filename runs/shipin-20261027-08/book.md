# 信封


### 第一章：信封上的邮戳

晨光穿过灰蒙蒙的天色，在冰台上投下斑驳的影子。老张站在冰台边缘，左手紧紧攥住一个蓝色信封，指节发白。他弓着背，努力把信封往外套口袋里塞。

“这是你的？”阿强的声音从背后传来，带着几分不满。

老张没回头，眉头皱得更紧了。“这不是废纸。”他低声嘟囔了一句，手指在信封上摩挲了几下，像是在确认它的存在。

阿强往前一步，右手伸向信封。“我天天在这儿收废品，这种东西不值钱。”

“别碰！”老张猛地侧身，护住信封，右手还沾着鱼腥味。他用力拽了一下，但信封纹丝不动。

“你凭什么占着？”

老张的目光落在冰台上，眼神有些恍惚。“这可能是有人丢的……”他喃喃自语，声音轻得几乎听不见。

阿强冷笑一声，伸手就要抢过去。

“别动！”老张突然提高了声调，右手猛地一挥，一把抓起旁边的小塑料袋，朝阿强扔去。

阿强闪身避开，脸色也变得严肃起来。他盯着老张的手，眼神中透出一丝警惕。

“你怎么知道这是重要东西？”阿强问道。

老张没有回答，只是低头看着手中的信封，目光复杂。他的手指轻轻拂过信封上的邮戳，像是在回忆什么。

阿强盯着他看了几秒，最终还是收回了手。他叹了口气，转身走向自己的垃圾车。

老张松了一口气，低头看了看信封，嘴角露出一丝微笑。他慢慢将信封放回口袋，抬头看向远方。

冰台上的阳光越来越亮，映照在他略显疲惫的脸庞上。他缓缓闭上了眼睛，似乎想起了什么。

阿强伸手探向老张的手背，指尖擦过那道陈旧的烫伤疤。

老张猛地缩回手，攥紧信封往怀里藏。

阿强咧嘴笑出一口黄牙，“你这是怕我偷看？”

老张喉结滚动两下，咬牙瞪着他。

阿强往前凑一步，一把扯住信封角，力道不大但稳。

老张急得直跺脚，却被自己冻僵的脚趾绊了一跤。

阿强顺势向前扑倒，膝盖砸在冰面上发出闷响。

老张慌忙扶起他，却摸到了裤兜里皱巴巴的一团纸。

阿强借势翻身站起，得意地晃了晃手腕。

老张忽然捂住胸口，脸色发白。

阿强凑近看他，眼神突然变得柔和。

老张咳了一声，从口袋掏出一张泛黄照片。

阿强接过照片，指着上面模糊的身影。“是你女儿？”

### 第二章：撕信风波

天还没亮透，鱼市街口的冰台已经开始忙碌起来。水汽凝结在铁架上，发出细微的滴嗒声。阿强蹲在角落里，右手捏着半截塑料袋，指尖沾着鱼腥味。他抬头望向冰台中央那张蓝色信封，眼神闪了闪。

“这是啥玩意儿？”阿强嘟囔了一句，声音混着晨风飘散在潮湿空气中。

他伸出右手，小心翼翼地撕开信封一角，动作像在处理一件贵重物品。纸张微微泛黄，边缘有些卷曲，像是被人反复翻动过。

“别撕坏了。”一个低沉的声音从身后传来。

阿强回头，看到老张正站在不远处，左手紧紧抓着信封，眉头皱得紧紧的。他的右手还沾着鱼腥味，指节发白，显然是用力过猛。

“你干啥？”阿强语气里带着几分不满，“这不是废纸吗？”

老张没有回答，只是盯着信封看了几秒，又低头看了看自己沾满鱼鳞的手。

“你说不定能帮上忙。”老张终于开口，声音不大，却带着不容置疑的力道。

阿强愣了一下，随即冷笑一声。“帮忙？我靠，我天天捡破烂，你还真当我傻。”

他说着，右手猛地一扯，信封裂开一道更大的口子。纸页哗啦一声展开，露出一张模糊的照片。照片上是一群人站在河边，背景模糊不清，但有人脸轮廓依稀可辨。

阿强眯起眼睛，仔细端详着照片上的面孔。“这……这人，我好像见过。”

老张一把抓住信封，用力往回收，指尖几乎掐进信纸上。

阿强手腕一翻，铁皮车底传来金属摩擦声，信封掉落在地上。

“你这是干什么？”老张皱眉，脚下一滑，差点踩到冰碴。

阿强蹲下身，用鞋尖碾了碾信封边缘，“这不是你该管的事。”

他忽然停住动作，低头看着照片，眼神有些恍惚。

“这张照片……”他喃喃自语，手指轻轻摩挲着照片边缘。

老张凑近一看，突然瞪大眼睛。“等等，这个背影……”

阿强猛地抬头，眼神变得锐利。“你怎么知道？”

“那不是我们镇上的小河吗？”老张声音发紧。

阿强沉默片刻，缓缓起身，把信封重新塞回铁皮车里。

“算你运气好。”他说着，推着车往街尾走。

老张站在原地，望着他的背影，攥紧了信封一角。

天刚蒙蒙亮，鱼市街口的冰台泛着冷光。老张蹲在鱼摊旁，左手紧紧抓着蓝色信封，右手指尖还沾着鱼腥味。阿强站在几步外，右手捏着半截塑料袋，左脚踩着铁皮垃圾车踏板，脖子上的铜铃叮当作响。

“这不是我丢的。”阿强突然开口，声音沙哑。

老张没说话，只是把信封往自己怀里缩了缩。

“我认得那个背影。”阿强往前迈一步，脸上的皱纹更深了些，“你别误会，我只是想知道这封信到底值多少钱。”

老张的手指微微发抖，他低头看着信封上的邮戳，像是第一次注意到那些字母。

“你要是敢动它，我就报警。”老张终于开口，声音比晨雾更冷。

阿强哈哈一笑，笑声却带着一丝苦涩。“报警？你以为警察会管这种小事？”

他伸出右手，指尖几乎碰到信封边缘。“你放心，我只想看看里面有什么。要是没什么特别的，我就把它当成废纸处理。”

老张咬住下唇，目光在信封和阿强之间来回游移。

“你到底是谁？”老张突然问道。

阿强停下脚步，回头看了他一眼，眼神复杂。“我是个收废品的。”

“那你为什么偏偏要碰这封信？”老张的声音低了下来。

阿强没有回答，只是低头看向手中的塑料袋，像是想起了什么。

“你知道吗？”阿强轻声说，“有时候，一封信比一袋塑料袋更重要。”

老张愣了一下，随即用力攥紧了信封。

“你最好还是别碰它。”老张警告道。

阿强笑了笑，转身推着车往街尾走去，铜铃声渐渐消失在晨风中。

老张站在原地，望着阿强的背影，久久没有动弹。

### 第三章：断秤风波

早晨的阳光斜照进杂货店玻璃窗，映出一片细碎的光斑。小梅坐在柜台后面，右手握着秤杆，食指关节微微发白。

“老张那家伙又在那儿跟人扯皮了。”

她低声嘟囔了一句，眼睛仍盯着外面的冰台。风卷起几片落叶，在店铺门前打着旋儿。她抬起左手，摸了摸挂在墙上的绿色植物，叶片上的露珠顺着叶脉滚落。

“今天鱼价涨得厉害啊。”

她忽然停住手指的动作，看着天花板的裂缝，嘴角浮起一丝苦涩的笑容。秤盘里躺着一条完整的鲤鱼，尾巴还在轻轻摆动。

“你别管他们，小心点。”

她转过脸，对着门口喊了一声，声音轻柔却带着几分严厉。风继续吹拂着屋檐下的铜铃，叮当声混着远处吆喝叫卖的声音传来。

小梅的手指慢慢放松下来，秤杆垂落在桌面上，发出一声细微的响。她望着门外那片晃动的光影，眼神变得遥远起来。

早上的阳光穿过玻璃窗，在地板上洒下一圈光晕。小梅坐在柜台后，手指搭在秤杆上，眉头微皱。她的目光时不时瞥向冰台的方向，像是在等什么人。

“老张啊，你可得当心些。”她自言自语，语气里带着几分担忧。

突然，冰台上传来一阵喧哗。小梅立刻站起身，快步走到门前，拉开门帘。风裹挟着水汽扑进来，掀起几片落叶。她望向外面，只见老张正和阿强在争抢那个蓝色的信封。

“你们两个别吵了！”她大声喊道，声音穿透了清晨的雾气，“信不是给你们抢的！”

老张和阿强愣了一下，随即又开始争论。小梅叹了口气，转身回到柜台前，重新拿起秤杆。她轻轻放在桌上，指尖摩挲着冰冷的金属。

“今天怎么这么安静？”她喃喃自语，抬头看向天花板的裂缝，眼神有些恍惚。

这时，门外又传来了脚步声。小梅警觉地抬起头，透过门帘望去，只见一个人影朝这边走来。她迅速拉上门帘，低声说道：“来了。”

晨光穿过窗帘缝隙，照亮了杂货店的木质地板。小梅站在柜台后面，手指轻轻抚过秤杆边缘的锈迹。她突然用力一扯，秤杆发出清脆一声断裂响，金属部件滚落地上。

“这秤太旧了。”她蹲下身，捡起一块残破的秤砣，对着阳光端详，“我得换个新的。”

外面传来鱼贩们收拾货物的声音。小梅站起身，推开门帘，看见老张正把最后一条鲤鱼放进塑料袋。她快步走上前，接过袋子，轻声说：“别弄丢了。”

老张点头，低头继续整理鱼摊。小梅回头望了一眼冰台，那里阿强正蹲在地上翻找什么东西。她转身回到柜台，从抽屉里取出一把钥匙，打开储物柜，拿出一卷新秤杆。

“这个应该够用了。”她把秤杆放在桌面上，轻轻推过去，“明天来取。”

阿强走了进来，手里还攥着那封蓝色信封。他直接坐在椅子上，把信封放在桌上。“你认得这玩意儿吗？”

小梅挑了挑眉，看着信封上的邮戳。“看起来像是有人丢的。”她说着，伸手想去拿，却被阿强抢先一步。

“这是我的。”阿强语气坚定。

小梅收回手，目光变得锐利。“信不是给你们抢的！”

### 第四章：鱼尾撞冰台

老张蹲在冰台上，右手拎起塑料袋，把一条鲤鱼往里塞。鱼鳞擦过他的指尖，带着寒气。他抬头看冰台对面，阿强正踮脚够那叠旧报纸，灰扑扑的。

“你别碰！”老张喊了一声，鱼尾巴扫出水渍，在冰面溅开细小的光斑。他低头把鱼肚朝外翻过来，露出鱼鳃，动作熟练得像在做手术。

阿强转过头来，手里还抓着半截塑料袋。“这破东西有什么好抢的？”他说着，往前凑了两步。

老张皱眉，左手已经扣住鱼鳍，防止滑脱。“这是活鱼。”他语气硬了些，“你不该在这里。”

阿强耸肩，嘴角泛起一丝笑意。“我收废品，什么东西不是废品？”

“那你摸过鱼吗？”老张没说话，只是继续把鱼往塑料袋里塞。鱼挣扎了几下，最后安静下来，肚子鼓鼓的。

阿强看着袋子渐渐饱满，又瞥了一眼老张的手腕——那里有道浅疤，像是被渔网划过的。

“这不是你的鱼。”阿强突然说。他指着袋子里的一条疤痕，眼神变得锐利起来。

老张停下手，愣了一下。他顺着阿强指的方向看去，那确实是条纹路，但并不是自己养的鱼。

“你怎么知道？”老张的声音低了一些。

阿强笑了笑，慢慢把手伸向塑料袋。“也许我们都在找同一个人。”

老张沉默片刻，终于点了点头。他松开手，任由那条鱼在袋子里轻轻晃动，就像小时候家里那只总是掉毛的小狗一样。

早晨六点半，阳光透过鱼市街口的棚顶洒下来，照在冰台上凝结的霜花上。老张蹲在鱼摊前，左手按住塑料袋的袋口，右手正往里塞一条鲤鱼。

“你这是要卖鱼还是养鱼？”阿强站在旁边，一只手拎着铁皮垃圾车，另一只手指了指塑料袋里的鱼。

老张没理他，继续把鱼往袋里放。袋子里已经装了几条，鱼鳞还在闪着光。

“我知道你在找什么。”阿强往前凑了一步，眼睛盯着袋子里那条有伤疤的鱼，“我见过那个人。”

老张的手停住了。他抬头看了阿强一眼，又低头看向塑料袋里的鱼。那些鱼的眼睛都睁着，像是在看他。

“你到底是谁？”老张低声问。

阿强笑了，嘴角带着一丝得意。“我只是路过而已。”

老张慢慢松开手，让塑料袋滑落一些。鱼在袋子里轻轻晃动，发出细碎的声音。

“你是不是也想知道那个信里说的是什么？”阿强突然说。

老张愣了一下，转过头看着阿强。他的目光落在对方脖子上的铜铃上。

“你要做什么？”老张问。

阿强耸耸肩，“我只是想知道，谁才是真正的主人。”

早晨六点半，雾气还未散尽。鱼摊旁的冰台反射出冷光，湿漉漉的地面上倒映着天际线的灰蓝。老张蹲在冰台边缘，左手压着塑料袋袋口，右手指尖沾了水渍，在鱼背上蹭了一圈。他正要把鱼提起来，却被阿强一把扯住手腕。

“别碰！”老张皱眉喊。

阿强咧嘴笑，手背上的冻疮泛着红。他身子往前凑，几乎贴着老张耳边：“你猜那封信里写的，到底是谁的名字？”

老张没说话，只是眯起眼睛看阿强腰间别着的小刀。他猛地甩开手，塑料袋一下弹开，鱼尾巴撞到冰面溅起水珠。阿强顺势扑过去抓塑料袋，却踩空摔了个趔趄。

“小心。”老张伸手扶住他胳膊。

阿强咬牙忍住疼，低头盯着塑料袋内侧有几道划痕。“你怎么知道我偷看了？”他梗着脖子问。

老张笑了笑，指指自己眼角的皱纹。“那天你在冰台上走来走去，我认得你的脚印。”

阿强哼了一声，把手伸向塑料袋另一端。老张忽然发力，整个身体往后仰，借力翻滚避开攻击。他落地时膝盖擦出血痕，但反而稳住了脚步。

“你想干什么？”阿强瞪着眼睛问。

老张从围裙兜里掏出一支圆珠笔，在鱼鳍上画了个记号。“这是我家养的鱼，”他说，“我要送它去城西的市场。”

阿强冷笑一声，弯下腰去抓鱼，却不慎碰到塑料袋绳子，整个人被拖倒在地。鱼在水中挣扎，掀起一片浪花。

老张趁机一脚踢开塑料袋，转身走向鱼摊另一边，手中拎着一包生菜。

### 第五章：鱼鳃上的裂痕

晨光穿过雾气，在鱼市街口洒下淡金色。阿强蹲在冰台边缘，左手拎着锈迹斑斑的铁皮垃圾车，右手正要把那条鱼拖进去。

“别动！”

老张突然从后面扑过来，一把攥住鱼尾巴，冰碴子溅到阿强脚背上。鱼挣扎着甩尾，鳞片撞得金属车身叮当作响。

阿强稳住身形，皱眉看着鱼身上那道暗红疤痕：“你认错鱼了？这条是昨天才捞上来的新鲜货。”

“这是老王家丢的。”老张的手指关节发白，指甲缝里全是鱼腥味，“他儿子昨晚还在找。”

阿强低头瞅着鱼腹部那串模糊的刻痕，忽然笑出声：“你们鱼贩都这么心善吗？我见过不少偷鱼贼，可没见过像你这样执着的。”

鱼在他怀里轻轻扭动，鳞片泛着水光。阿强眯起眼睛，喉结滚动了一下，伸手摸了摸鱼鳃：“真是奇怪，为什么偏偏是这种鱼？”

鱼在阿强怀里轻轻扭动，鳞片泛着水光。他眯起眼睛，喉结滚动了一下，伸手摸了摸鱼鳃：“真是奇怪，为什么偏偏是这种鱼？”

阿强的左手攥紧了塑料袋，指节发白。他抬头望向冰台尽头，那里站着老张，正用左手抓着信封，眼神里带着几分期待。

“这不是你的。”老张的声音低沉，像是从冰面下传来，“这封信我先看到的。”

阿强冷笑一声，右手猛地拽住塑料袋，鱼扑腾着撞在他胸口。“你凭什么管我的事？”他的嗓音里透着一丝焦躁，“反正早晚都是废品。”

老张向前迈了一步，围裙下的身体微微前倾。“你别碰那封信。”他低声说，目光落在信封上，像是怕它突然消失。

阿强突然用力一扯，塑料袋被拉出一道裂痕，鱼猛地跃起，在空中划出一道弧线。老张本能地抬手挡了一下，却还是被溅了满脸水珠。

“哎呀！”老张皱眉擦了擦脸，手背上的鱼腥味混着水渍更浓了些。

阿强看着地上翻滚的鱼，嘴角露出一丝笑意。他蹲下来，伸手去捞那条挣扎的鱼，指尖刚碰到水面，又迅速缩回。

“你到底想知道些什么？”他对着老张问道，语气比刚才柔和了些。

老张没有回答，只是盯着那条鱼看了很久，像是在等它停下来喘口气。

### 第六章：鱼尾撞冰台

天刚蒙蒙亮，鱼市街口的冰台泛着霜气。老张用右手拎起一条鲤鱼，鳞片在晨光里闪出细碎的光泽。他皱了皱眉，指腹蹭过鱼尾巴的伤口，那道裂口还没愈合，像条蜈蚣爬过的痕迹。

“这条鱼你别动！”老张嗓音沙哑，攥紧鱼尾的手背青筋凸起，“这是今早最先捞上来的一条。”
