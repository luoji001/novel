# 药瓶上的名字


### 第一章：登记本掉落的瞬间

清晨的阳光透过窗帘缝隙洒进输液室，照在冷白色的瓷砖地板上。

李秀兰站在输液架旁，双手紧贴身体，双眼直盯着那瓶写着张美玲名字的药水，手指微微发抖。

周玉兰抬起右手，将登记本狠狠按在输液架上，纸页哗啦作响。

“这是规定！”她的声音清脆有力，带着不容置疑的威严。

李秀兰向前迈了一步，红袖章随着动作晃动，在晨光中泛起淡淡的红色光泽。

周玉兰后退半步，手中的塑料篮轻轻放在地上，马尾辫随着转身的动作轻轻摆动。

她将登记本重新整理好，指尖划过那些密密麻麻的笔迹。

“你连诊断单都没交。”她说着，目光扫向李秀兰攥着的皱巴巴的单据。

李秀兰低头看着自己的手，喉结上下滚动了一下。

周玉兰突然伸手拽住登记本的一角，将其牢牢固定在输液架上。

“别动。”她的语气变得柔软了些，却依然带着不容商量的力量。

李秀兰的手指不自觉地握紧了拳头，指甲深深掐入掌心。

李秀兰的手指已经碰到登记本的边缘，纸页在她指尖微微发颤。

周玉兰忽然松了手，登记本哗啦一声掉在地上。

李秀兰弯腰去捡，手指抚过纸页上的墨迹，像是在确认某个真相。

“这是你的。”她抬头看周玉兰，眼神里有种说不出的情绪。

周玉兰站在原地，望着她手中泛黄的纸张，嘴唇微动，却没发出声音。

李秀兰将登记本收进外套口袋，转身准备离开。

周玉兰突然叫住她：“等等。”

她快步走过来，伸手拉住李秀兰的衣袖，“你今天能不能别再来了？”

李秀兰愣住了，回头看向她，眼里有些惊讶。

周玉兰低头看着自己的鞋尖，声音轻得像风里飘来的雪，“我女儿也在这里治病。”

李秀兰沉默了一瞬，点了点头。

周玉兰松开手，目送她走出输液室的大门，阳光透过玻璃窗洒进来，在地面画出一道光带。

### 第二章：红袖章贴胸口

上午九点的输液室冷得像冰窖，窗玻璃蒙着雾气。李秀兰坐在输液椅上，右臂戴的红袖章垂在输液架边上，像是被谁不小心扯了下来。

周玉兰抱着塑料篮站在门口，银色的胸牌在她胸前晃荡。“你怎么又来了？”她说，语气里带着责备。

李秀兰低头看着手中的诊断单，“我今天带了。”她的手指捏紧纸角，指节发白。

周玉兰抬起左手，塑料篮里的药瓶哗啦作响。“这是昨天剩下的。”她往前走了一步，手背上的静脉清晰可见。

李秀兰忽然抬手抓住输液架，身子往后仰，红袖章顺着手臂滑落，在地上打了个旋儿。

“你是不是觉得我不够格给你看病？”她的声音有点抖。

周玉兰停下脚步，脸上的表情微微变了。“我不是这个意思。”

李秀兰盯着那片红色布料，眼神有些迷离，好像看到很久以前有人穿着它陪自己熬过夜。

周玉兰蹲下身捡起红袖章，指尖碰到布料的一瞬间，手腕上的针眼闪了一下光。

“你还记得吗？”李秀兰突然开口，声音比刚才低了许多，“你说我们都是为病人好。”

周玉兰愣住了，抬头看了她一眼，发现她的眼圈发红。

“我知道。”她说，轻轻把红袖章放回李秀兰手里。

李秀兰接过，右手紧紧握住，像是怕它再溜走似的。

周玉兰扶了扶眼镜，目光扫向输液架上空荡荡的位置。

“这已经是第三次了。”她语气平静，“按规定，没有诊断单不能用药。”

李秀兰的手指摩挲着红袖章边缘，声音有些发颤：“可我明明交过了……”

“你没交。”周玉兰的声音像冰碴子一样冷，“而且，这张诊断单是上周才收到的。”

李秀兰怔住了，手指无意识地揉着袖口的褶皱。

“你知道我为什么坚持吗？”她忽然抬头看着周玉兰，“每次看到病床前的家属，我都想起自己的女儿。”

周玉兰沉默了一秒，低头看了看手中的登记本。

“这次不一样。”她低声说，“病人情况不稳定，不能冒险。”

窗外飘起细雪，阳光透过玻璃照进来，在地上投出一道金线。

李秀兰望着那道光影，喉结微微滚动：“我已经等了三天。”

周玉兰的目光柔和了些：“明天再来吧，我会给你安排。”

李秀兰盯着她的胸牌看了许久，最后只是点了点头。

李秀兰的指尖触到红袖章边缘，指节泛白。

她猛地将袖章扯过头顶，贴在胸口。

周玉兰愣了一下，塑料篮碰倒在地上，药瓶滚出一排。

“这是我的。”李秀兰的声音比清晨的雾气还冷。

周玉兰弯腰捡起塑料篮，手指擦过沾着药水的台面。

“这是院里的规定。”她说，“不能随便带进输液室。”

李秀兰咬住下唇，眼神像冻僵的湖面。

周玉兰看着她颤抖的手背，忽然松开篮子。

“你女儿……现在怎么样？”她轻声问。

李秀兰的眼泪落进袖章褶皱里，洇出深色痕迹。

“她今天早上走的。”她说。

窗外的雪越下越大，输液架上的药水滴落，发出细小的声响。

### 第三章：胸牌上的刻字

清晨九点半，输液室门口站着几个等着打针的病人。李秀兰站在护士站门口，看着周玉兰胸前挂着的银色胸牌。她伸出左手，指尖轻轻碰了碰那块牌子。

“你这牌子挂得歪了。”李秀兰低声说。

周玉兰低头看了一眼，随即抬头看向李秀兰。“这是规矩。”

“可我女儿也在这儿治。”李秀兰的声音有点发抖，“她要是没这个牌子，能不能打针？”

周玉兰的手指在登记本上停顿了一下，然后继续翻页。“每个病人都有自己的牌子。”

李秀兰又往前凑了一步，脸上的表情变得复杂。“那你女儿呢？她的牌子在哪？”

周玉兰的目光微微一闪，但很快恢复平静。“她在病房。”

李秀兰咬了下嘴唇，转身离开护士站。走到输液室门口，她回头看了一眼，手指无意识地摩挲着左耳垂的黑痣。

周玉兰突然起身，快步追出去。她手里拎着装满药瓶的塑料篮，一边走一边喊：“李秀兰！”

李秀兰停下脚步，回头看了她一眼，眼神里带着一丝疑问和愤怒。周玉兰走近几步，语气缓和了一些：“你知道吗？这块牌子不是随便挂的。”

李秀兰沉默了一会儿，然后点点头。“我知道。”

李秀兰站在输液室门口，手指摩挲着左耳垂的黑痣，目光落在远处的护士站。

周玉兰从护士站出来，手里拎着塑料篮，快步走到她面前。她的马尾辫随着步伐轻轻晃动，胸前的银色胸牌在阳光下闪了一下。

“你到底想干什么？”周玉兰的声音有些严厉，但更多的是疲惫。

李秀兰没有立刻回答，而是低头看着自己的左手，那里还攥着一张皱巴巴的诊断单。

“我只是想看看这块牌子。”她说，声音轻得几乎听不见。

周玉兰愣了一下，随即摇头。“这不是你能看的。”

李秀兰抬起头，眼神坚定地看着她。“我有权知道。”

周玉兰沉默了片刻，然后缓缓伸出手，将胸牌取下来递给李秀兰。“如果你想知道，就拿去看看吧。”

李秀兰接过胸牌，指尖轻轻抚过上面的刻字，像是在抚摸一件珍贵的宝物。

“这是你的工作证？”她问。

“是我的职责。”周玉兰笑了笑，“但我也是人，也有家人。”

李秀兰点了点头，把胸牌放进口袋，转身准备离开。

周玉兰叫住她。“等等。”

李秀兰停下脚步，回头看向她。

“以后别再来输液室。”周玉兰说，“我不希望再见到你。”

李秀兰没有回应，只是深深地看了她一眼，然后慢慢走开了。

护士站的玻璃窗透进微弱的冬日阳光，照在周玉兰胸前的银色胸牌上。她正低头整理一叠病历，忽然听到身后传来一声轻响。

“这牌子太重了。”李秀兰的声音带着几分调侃，“每天都要背着它跑来跑去。”

周玉兰抬起头，看着李秀兰手中晃动的胸牌。那是她早上刚领来的，上面还留着医院盖章的新漆味。

“这不是给你玩的。”周玉兰语气平静，手指轻轻点了点李秀兰的手腕，“它是我的身份证明。”

李秀兰把手缩回来，嘴角微微上扬。“我知道你是谁，我见过你女儿。”

周玉兰的脸色突然变了，手中的文件差点掉落。她迅速抓住纸页，眼神变得严肃起来。

“你说过不想来输液室。”周玉兰低声说，“那就不该再来。”

李秀兰站在原地，望着窗外飘落的雪花。她的影子投在墙上，像一只沉默的猫。

### 第四章：药瓶跌落的瞬间

上午十一点，输液室内冷气足，玻璃窗结着薄霜。李秀兰坐在输液椅上，左手指尖蹭了蹭桌面上的登记本，眼神盯着输液架上那个空位。

“那是我女儿的。”她突然开口，声音沙哑。

周玉兰从药篮里抬起头，手中的塑料篮微微一顿。“不行。”

李秀兰猛地站起来，右臂的红袖章擦过输液架，左手攥紧的诊断单被扯出一道褶子。“你凭什么不给我女儿用药？”

周玉兰往前一步，右手按住登记本。“这是规定。”

李秀兰扑过来，伸手去够输液架上的药瓶。她的手指碰到瓶子的一瞬间，周玉兰迅速往后退了一步。

“你疯了吧？”周玉兰的声音提高了一些。

李秀兰的手悬在空中，眼圈发红。她忽然笑了，笑得有些扭曲。“你们这些医生，一个个都是一样的嘴脸。”

周玉兰低头看着登记本，嘴唇动了动，最终没有说什么。

李秀兰转身走到输液椅边，一把将椅子推到输液架旁边。“坐这儿吧，反正你也懒得管。”

周玉兰愣了一下，随即摇头。“你以为我是谁？”

李秀兰冷笑一声，拿起输液架上的药瓶。“那你告诉我，这瓶药是谁的？”

周玉兰看着她，目光沉了下来。“是你女儿的。”

输液椅靠在墙边，金属支架泛着冷光。

李秀兰盯着输液架上的药瓶，手指摩挲着瓶子表面的标签。

周玉兰站在她身后，双手撑在登记本上，目光紧锁着那瓶药水。

“你说这是你女儿的？”李秀兰凑近了些，鼻尖几乎碰到玻璃瓶。

周玉兰没动，只是轻轻叹了口气。“我女儿还在病房里躺着呢。”

李秀兰的手指收紧了一些，指甲陷进掌心。“那你怎么不给她挂胸牌？”

周玉兰抬头看了她一眼，眼神平静却带着一丝疲惫。“因为她还没醒来。”

冷风吹过输液室的窗缝，发出轻微的呜咽声。

李秀兰盯着那瓶药水，嘴角抿得死紧。她的左手还握着那份皱巴巴的诊断单，像抓住最后一线希望似的。

周玉兰没有转身，但手指已经悄悄摸到了胸前的护士长胸牌。那是枚银白色的牌子，在昏暗的灯光下泛着微光。

“反正她也治不好。”李秀兰突然低声说道，“不如送她走吧。”

她伸出手，隔着几寸距离去够那瓶药水。动作很轻，像是怕惊醒了什么。

周玉兰终于转过身，目光如刀锋般扫过去。“现在可不是讨论这个的时候。”

她快步向前一步，拦在药瓶前面。手中的登记本哗啦作响，纸页翻飞间露出背面密密麻麻的名字。

李秀兰眯起眼睛，忽然笑了起来。“那你女儿呢？她是不是也有这样的病历？”

她抬起脚，对着输液椅就是一脚。椅子晃了晃，随即轰然倒塌。药瓶跌落在地，滚出好远。

周玉兰蹲下身子，捡起一只破碎的药瓶。玻璃碎片反射着苍白的灯光，映出她眼角的泪痕。

“你到底明白不明白？”她抬起头，声音有些发抖，“这不仅仅是一瓶药。”

李秀兰看着地上散落的药瓶，忽然低下了头。那一瞬间，她眼中的光芒消失了，就像窗外最后一丝天光也被黑夜吞没了。

### 第五章：药瓶坠地的瞬间

李秀兰站在药房货架前，手指悬停在一瓶透明液体上方。她盯着瓶子上那个熟悉的名字，眉头紧锁。周玉兰从身后走来，手里握着登记本。

“这瓶药不能给。”周玉兰停下脚步，语气平静。

李秀兰的手指微微颤抖，眼神里闪过一丝痛苦。“这是张美玲的药，我女儿……”

“按规定，没有诊断单不能使用。”周玉兰往前一步，挡在药瓶前。

李秀兰突然抓住周玉兰的手腕，指甲陷入皮肤。“你明明知道那是我的孩子！”

周玉兰皱眉，慢慢抽回手。“我只知道这是你的病人。”

药瓶在架子上晃动，发出轻微的碰撞声。李秀兰的眼泪顺着脸颊滑落，落在地上。周玉兰低头看去，神情复杂。

药瓶在输液架上轻轻摇晃，发出细微的咔嗒声。李秀兰盯着那个标签，手指微微发抖，眼眶泛红。

“你不该这样对她。”她低声说，声音有些哽咽。

周玉兰站在旁边，双手交叉抱胸，语气平静却带着不容置疑：“这是医疗规范，我不可能因为个人感情破坏流程。”

李秀兰猛地抬起头，眼里含着泪水，“她是唯一还在等我的人了！”

周玉兰愣了一下，随即摇头，“可这不是你能决定的事。”

李秀兰向前迈了一步，几乎要碰到药瓶，“你知道她多想见到我吗？”

周玉兰沉默片刻，终于叹了口气，“我知道，但我也知道风险有多大。”

李秀兰紧紧握拳，指节发白，“那你为什么还要让她走这条路？”

冷风从窗户缝隙钻进来，在药房门口凝结成霜花。

李秀兰站在药品货架旁，目光紧盯着那个贴着标签的玻璃罐。她的呼吸有些急促，脸颊泛红，像是刚跑过一段路。

周玉兰拿着登记本站在她面前，指尖轻轻敲打纸页。“这是规矩。”她说得很轻，却带着不容置疑的力量。

李秀兰的手伸向玻璃罐，手指微微颤抖。“可是这瓶药……”她停顿了一下，喉间发出哽咽的声音，“这是我女儿最后的愿望。”

周玉兰看了她一眼，眼神里闪过一丝犹豫。她慢慢走近一步，语气缓和了些：“我理解你的心情。但是这不只是你的事。”

李秀兰的眼泪终于落下来，滴在水泥地上。“我每天都在等着她回来啊！”她哭喊着，声音嘶哑，“我已经等得太久了。”

周玉兰低头看了看登记本，又抬头看向李秀兰，眼中流露出复杂的情绪。“我会尽力帮你。”她轻声说道，然后转身准备离开。

李秀兰突然抓住了周玉兰的胳膊，力道很大。“你真的愿意帮我？”她的眼神充满期待和怀疑。

周玉兰没有回答，只是轻轻地摇了摇头。

### 第六章：药瓶跌落的瞬间

县医院输液室，冬日阳光斜照进来，在地上拉出长长的影子。李秀兰站在输液架旁边，双手紧握着一张皱巴巴的诊断单，眼神盯着输液架上那个空着的位置。

“这瓶药，我女儿需要。”她低声说。

周玉兰从塑料篮里拿出一瓶药水，放在登记本上。“按规定，这个位置不能放。”

李秀兰往前一步，右手伸向输液架，手指碰到瓶子边缘。“我女儿快不行了，你懂不懂？”

周玉兰迅速抓住她的手腕，力道不小。“这是规矩，不是你一个人的事。”

李秀兰用力挣脱，脸色发青。“你们医院就是这么对待病人吗？”

周玉兰松开手，转身走向护士站。“我去请示主任。”

李秀兰站在原地，望着输液架上空荡荡的位置，嘴唇微微颤抖。

周玉兰回来时，手里拿着一张新的处方单。“这次可以特殊处理。”

李秀兰眼睛一亮，却突然停住，看着输液架上又多了一个空位。“那……那边呢？”

周玉兰低头看了眼手中的处方单，语气有些迟疑。“那是另一个病人的。”

李秀兰上前一步，伸手抓住输液架边缘。“可我女儿比那个病人更需要这个！”

周玉兰后退半步，扶了扶眼镜。“每个病人都是重要的，但程序不能乱。”

李秀兰盯着输液架上新留下的空缺，手指紧紧捏住处方单一角。“那就让我看看，这程序到底哪里不对。”

周玉兰瞥了一眼墙上的钟，低声说道。“现在已经是下午三点四十了。”

李秀兰猛地抬头，眼神锐利如刀。“所以你就打算等到明天再给她用药？”

周玉兰沉默片刻，终于叹口气，拿起电话拨打号码。

李秀兰突然拽住输液架的横杆，整个人向后仰去。

周玉兰迅速扑过来，双手撑在输液架两侧，死死抵住摇晃的金属支架。

“别动！”周玉兰的声音带着不容置疑的命令。

李秀兰咬牙瞪着她，嘴角渗出血丝，却仍不肯松手。

“你这是在破坏医疗设备。”周玉兰的指甲陷入金属边缘，发出细碎的刮擦声。

李秀兰突然松开手，输液架发出一声闷响向前滑去。

周玉兰来不及反应，被撞得踉跄几步，手中的塑料篮翻倒在地，药瓶滚落一地。

“我女儿今天就要做手术。”李秀兰弯腰捡起一张病历卡，声音发抖。

周玉兰蹲下身，用围裙擦掉地上沾染的药水痕迹，抬头看着她的眼睛：“按规定，这个药不能给她用。”

“为什么？”李秀兰突然抓住她的衣袖，力道大得惊人。

周玉兰手腕一抖，挣脱开来，转身走向护士站，取下挂在墙上的钥匙。

李秀兰跟上去两步，突然停下脚步，盯着她胸前的胸牌看了很久。

周玉兰回头望她一眼，语气缓和了些：“如果你一定要这么做，我可以帮你联系医生。”

李秀兰愣住了，手指轻轻摩挲着胸牌上的姓名缩写。
