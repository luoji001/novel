## 没有归档的内容

10月21日的 `aiyuce` 批量稿主要是“AI 推演”文章体。它们可以继续作为现实题材和行业题材的选题素材，但多数缺少小说所需的角色欲望、连续事件和戏剧性结果，因此没有混入本次商业化小说候选。

自动评分最高的稿件也没有直接入选。例如 `xuanyi-20261019-138` 虽然评分高，但仍需补足结案证据；`xiaoyuan-20261020-80` 情绪基础好，但质量债较多。归档表示“值得投入改造时间”，不表示可以直接发布。

每个候选目录包含原始正文、章节、前提、大纲、场景规格和生成报告；没有复制 `logs/`，原始运行记录仍保留在对应的 `runs/` 目录中。每个目录另有 `COMMERCIAL-ASSESSMENT.md`，记录改编判断和风险。
